# Jakarta Hotel Review Sentiment Analysis Website

**Jakarta Hotel Review Sentiment Analysis Website** is a sentiment analysis web application developed using **Python** and **Streamlit** to analyze customer reviews of hotels in Jakarta.

The application uses a **Support Vector Classifier (SVC)** model to classify hotel reviews based on their sentiment and provides an accessible interface for analyzing customer perceptions.

## 🏨 About the Project

This project was developed to provide a structured solution for analyzing sentiment within hotel reviews in Jakarta.

Hotel review data was collected through web scraping using **SerpAPI**, processed for sentiment analysis, and used to train a Support Vector Classifier model.

The trained model is integrated into a Streamlit-based web application, allowing users to submit review text and receive sentiment predictions directly through the interface.

## 📊 Sentiment Analysis

The application analyzes hotel review text and predicts its sentiment using a trained **Support Vector Classifier (SVC)** model.

User input is processed through the same preprocessing pipeline used during model development before being passed to the classifier for prediction.

## 🔍 Data Collection

The dataset used in this project consists of hotel reviews from Jakarta.

Review data was collected using **SerpAPI**, providing the source data required for preprocessing, model training, and sentiment classification.

## 🤖 Machine Learning Model

The sentiment classification model is built using **Support Vector Classifier (SVC)**.

The model is trained on processed hotel review data and integrated into the web application to provide sentiment predictions from user-submitted reviews.
